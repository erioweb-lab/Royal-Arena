# 로얄 아레나 — 지휘관 프로필 닫기 수복 및 로얄 판타지 UI/버튼/텍스트 통합 개선 계획

지휘관 생성/선택 후 모달이 닫히지 않는 결함을 완벽히 수복하고, 지휘관 선택/생성 시 자동 닫기 UX를 도입하며, 사용자가 선택한 **로얄 판타지 골드 & 딥 네이비(Royal Fantasy Gold & Dark Navy)** 디자인 컨셉에 맞춰 모든 화면의 패널, 버튼, 텍스트 레이아웃을 통일감 있게 정렬하고 보강합니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 사용자가 답변한 선택지에 맞춘 핵심 개선 방향입니다:

- **Confirmed Decision 1 (지휘관 생성/선택 및 닫기 결함 수복)**:
  - '선택' 또는 '새 지휘관 생성' 완료 시 모달이 자동으로 즉시 닫히도록 개선합니다.
  - 수동 '닫기'(`btn-prf-close`) 버튼 및 배경 클릭 시 이벤트 수신기 바인딩 보장 및 확실한 `hidden` 클래스 적용을 보장합니다.
- **Confirmed Decision 2 (로얄 판타지 골드 & 딥 네이비 디자인 컨셉 통일)**:
  - 타이틀, 버튼, 패널 헤더에 `Jua` 입체 골드 텍스트 및 양각 금속 보더(`border: 2px solid #FFD54F`, `box-shadow: 0 4px 14px rgba(255,179,0,0.3)`)를 적용합니다.
  - 패널 배경을 고급 로얄 네이비 엠보싱 패널(`linear-gradient(180deg, #182848, #0b1426)`)로 통일합니다.
- **Confirmed Decision 3 (지휘관 프로필 2열 그리드 및 상태 칩 정렬)**:
  - 프로필 모달 내부 레이아웃을 깔끔한 2열 입력을 갖춘 구조화된 그리드로 재구성합니다.
  - 현재 활성화된 지휘관에는 골드 상태 칩(`● 사용 중`)을 명확히 부착하여 가시성을 높입니다.

## 1. Overview & Core Concept

- **목표**: 지휘관 프로필 상의 자바스크립트 모달 제어 결함(닫기 불능)을 해결하고, 게임 컨셉에 어울리는 고급 판타지 아레나 UI 스타일을 전 스크린에 일관되게 적용.
- **개선 화면**:
  1. **지휘관 프로필 모달 (`#overlay-profile`)**:
     - 닫기 버튼 이벤트 핸들러 보강 및 생성/전환 성공 시 자동 `ov.classList.add('hidden')`.
     - 2열 입력 그리드(이름 변경 / 새 지휘관 생성) 및 활성 지휘관 엠블럼/상태 칩 정렬.
  2. **메인 타이틀 및 액션 버튼군 (`#screen-title`, `#title-actions`)**:
     - 로얄 판타지 골드 입체 보더 및 버튼 높이/간격 정렬.
  3. **팝업 패널 공통 (연구소, 명예의 전당, 게임 방법, 결과 정산)**:
     - 스크롤바 없는 `100dvh` 피팅 및 입체 골드 베벨 헤더/버튼 통일.

## 2. Technical Root Cause & Fix Strategy

### A. 지휘관 모달 닫기 실패 원인 분석
- `profNew()` 또는 `profSwitch()` 호출 시 `renderProfileList()`만 실행되고 모달 닫기 로직이 누락됨.
- `#btn-prf-close` 및 오버레이 수신기 바인딩 시 동적 이벤트 재바인딩이나 CSS `pointer-events` 가림 현상 발생 가능성 차단.
- **수복 방안**:
  1. `btn-prf-close` 클릭 시 `ov.classList.add('hidden')` 및 `ov.style.display = 'none'` 이중 보장.
  2. `profSwitch()` 및 `profNew()` 성공 시 `toast()` 출력과 동시에 모달 즉시 닫기.

### B. UI/CSS 스타일 및 그래픽 컨셉 규격
```css
/* 로얄 판타지 골드 & 네이비 토큰 */
--rf-gold: #FFD54F;
--rf-gold-glow: rgba(255, 213, 79, 0.45);
--rf-navy-dark: #0b1426;
--rf-navy-panel: linear-gradient(180deg, #182c4d 0%, #0d1a30 100%);
--rf-border-gold: 2px solid #FFD54F;
--rf-btn-primary: linear-gradient(180deg, #FFC107 0%, #E65100 100%);
```
